# Demo curriculum

`grade6-maths-teaching-plan.pdf`: a synthetic 4-page Grade 6 Mathematics annual teaching plan (one page per term).
The topics match the `teacher-curriculum-map` board (Hillview Primary, class 6B Mathematics). Percentages is listed in
Terms 3 and 4 and "Rounding off" is marked as a Grade 5 item on purpose, so the drafter has two topics to flag with a check.

Source: written for this repo, not copied from any ministry document. The DBE CAPS Intermediate Phase Mathematics and
Grade 6 Annual Teaching Plan PDFs were not downloaded (the guessed education.gov.za URL returned 404 on 27 Oct 2026),
so the synthetic plan is used. Swap in the official PDFs later by dropping them in this folder and uploading them as
curriculum documents.

Synthetic data only. Regenerate with any PDF writer; there is no build step.
