# Compliance with the challenge rules

One row for each rule sentence of the African Agentic AI Design Challenge page for the Education track (The Long View). The rule is in the page's words, except that the page's long dashes are written as hyphens. Checked against the code on this branch, on 11 November 2026.

Status is one of: **met** (a proof exists and was opened), **met with a limit** (the limit is written), **not met**, or **the owner's** (only the owner can do or confirm it: the video, eligibility, the submission itself).

GitHub runs cited are all green and all ran the whole CI job on a clean Ubuntu machine: `./start.sh --ci`, typecheck, the whole `pnpm test`, and the demo path on a phone. They are run 42925958625 (develop at 6691e99, the latest), run 42916065533 (develop at 39723ab) and run 42910274227 (develop at 734a0b7), all in the repository AI-Native-Ventures/jemma. A test (`packages/profiling/test/docs.test.ts`) checks that every status below is one of the four, and that every file named in a row exists.

## Model cards read

The licences of the open-weights models were read on the Hugging Face model cards on 11 November 2026. The weights are public, not gated, and have a repository of files. The OpenRouter ids in `packages/runner/src/goose.ts` name the same models, but the hosted copy was not compared with the downloadable files.

- `nvidia/nemotron-3.5-super-vl`: https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Super-VL-120B-A12B-BF16. Licence: OpenMDW License Agreement, version 1.1 (https://openmdw.ai/license/1-1/). The card says "This model is ready for commercial or non-commercial use."
- `nvidia/nemotron-3.5-lightning`: https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16. Licence: OpenMDW-1.1.
- `nvidia/nemotron-3-ultra-550b-a55b`: https://huggingface.co/nvidia/NVIDIA-Nemotron-3-Ultra-550B-A55B-BF16. Licence: OpenMDW-1.1.
- `google/gemma-4-31b-it`: https://huggingface.co/google/gemma-4-31B-it. Licence: Apache 2.0 (the card's header, linked to Google's Gemma 4 licence page).
