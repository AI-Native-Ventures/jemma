## Why learners make this mistake
Learners add the top and bottom numbers separately because they see a fraction as two whole numbers instead of one quantity.

## Missing basic skill
Making denominators the same (equivalent fractions).

## Explanation for the teacher (two sentences)
The bottom number tells you how many equal parts the whole is cut into, so it is not added like a counting number. First make the denominators the same, then add only the top numbers.

## Reteach lesson
- **Title:** Adding fractions with different denominators  
- **Audience:** Amina, Thabo and Naledi  
- **Minutes:** 10  
- **You need:** Fraction strips or paper squares, a common-denominator chart, pencils and exercise books  

**Steps:**
1. (2 min) Show 1/2 and 1/4 on fraction strips. Ask what each bottom number means: how many equal parts the whole is cut into.
2. (2 min) Turn 1/2 into 2/4 so both fractions have the same bottom number.
3. (2 min) Add only the top numbers: 2/4 + 1/4 = 3/4. The bottom number stays 4.
4. (2 min) Do 2/3 + 1/6 together: make sixths, then add the tops.
5. (2 min) Learners write 1/2 + 1/4 on their own while the teacher walks around checking.

**Exit question:** What is 1/2 + 1/4?
