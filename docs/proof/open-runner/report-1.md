## Gap 1: Adding fractions with different denominators

**Why:** Learners treat the top and bottom of each fraction as separate whole numbers, so they add the tops together and the bottoms together instead of making the pieces the same size first.

**Missing basic:** Equivalent fractions with the same denominator

**Explanation (teacher script):** You can only add fractions when the pieces are the same size. First turn them into equivalent fractions with the same denominator, then add the tops.

## Reteach plan

**Title:** Adding fractions with different denominators
**Audience:** Amina, Thabo, Naledi
**You need:** Fraction strips or paper squares, markers
**Total minutes:** 10

**Steps:**
1. (2 min) Show 1/2 and 1/4 on fraction strips. Point out that the pieces are different sizes.
2. (3 min) Cut the half into two quarters. Now both fractions use quarters: 2/4 + 1/4.
3. (3 min) Add the tops only: 2 + 1 = 3, so the answer is 3/4. The bottom stays 4.
4. (2 min) Try 2/3 + 1/6 together: turn 2/3 into 4/6, then add.

**Exit question:** What is 1/2 + 1/4? Show me with the strips.
