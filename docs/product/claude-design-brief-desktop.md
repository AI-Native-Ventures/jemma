# Claude Design brief: Jemma Desktop

Paste the block below into the "Jemma v1 screens" canvas in Claude Design. It adds the desktop boards to the same canvas.

```text
Add boards for Jemma Desktop to this canvas. Same brand and rules as the other Jemma boards: lowercase "jemma" wordmark with the gem dot, ink #1F1D36, coral #FF6A4D, ground #F7F7FA, white cards, Outfit, light theme only, no em dashes in any copy, made-up people only.

WHAT JEMMA DESKTOP IS
A Mac app for teachers and parents. Many already pay for Claude or ChatGPT. Jemma Desktop lets their own Claude Code or Codex do Jemma's AI work (reading papers, writing lessons) on that subscription, so they pay nothing extra. Phones still snap tests; the laptop does the thinking. Without Jemma Desktop, Jemma's cloud does the work on free models.

DEMO CAST
Ms Banda on her MacBook. Claude Code is installed and signed in. Codex is not installed. Class 6B Mathematics at Hillview Primary.

BOARDS (Mac window 1200 x 800 unless noted)
1. Desktop · Pair: "Sign in to Jemma Desktop". Enter the 6-character code shown in Jemma on your phone or browser, or sign in with email.
2. Desktop · Choose your AI: two cards, Claude Code and Codex, each with its status: "Installed and signed in", "Installed, not signed in" (hint: open Terminal and sign in), "Not installed" (link: How to install). A plain privacy note: "Your Claude or ChatGPT plan may use what it sees to improve its models unless you turn that off in its settings. Jemma only sends schoolwork." Main button: "Run Jemma's work on Claude Code".
3. Desktop · Main window: the normal Jemma laptop screens inside the Mac window, with a slim status strip at the top: "Jemma Desktop · Claude Code · Ready". Show the strip in 4 states: Ready, Working ("Reading 3 of 5 papers"), Paused, Can't run ("Claude Code hit its usage limit").
4. Desktop · Menu bar menu (about 320 wide): status line, the job in progress with a progress bar, the last 3 jobs with times ("14:12 Read 5 papers, 1 unsure"), Pause Jemma, Open Jemma, Settings.
5. Desktop · Job stopped: "Couldn't finish reading Sipho's paper. Claude Code stopped: usage limit reached." Buttons: "Try again at 17:00" and "Run in the cloud this time".
6. Phone 390 · Where Jemma's AI runs: a setting in the teacher's class settings and the parent's account. Two options: "Jemma cloud (free models)" and "My Jemma Desktop (Claude Code or Codex)", with the desktop's status line under the second ("Ms Banda's MacBook · Claude Code · Ready").
7. Phone 390 · Needs you item: "Jemma Desktop is off. 5 papers are waiting." Buttons: "Open Jemma Desktop" and "Run in the cloud this time".

DELIVER
All 7 boards, with the states listed for boards 3 and 4. Title each board starting with "Desktop ·" (or "Teacher ·" / "Parent ·" for the phone boards), so the build can find them.
```
